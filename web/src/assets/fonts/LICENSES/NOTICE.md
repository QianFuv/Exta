Exta distributes the font data under SIL Open Font License 1.1. The merged font
is JetBrainsLxgwNerdMono Version 1.3, Copyright (c) 2024 lvbibir. Its components
are JetBrains Mono NL Nerd Font Mono (Nerd Fonts v3.4.0, JetBrains Mono v2.304),
LXGW WenKai Mono GB Screen v1.521 (Regular CJK), and LXGW ZhenKai GB v0.819
(Bold CJK). MIT notices in Nerd Fonts describe tooling; they do not replace
the OFL applying to the font data.

All 344 Regular and 324 Bold WOFF2 payloads match the official merged-font v1.3
split archive by SHA-256. Local shard filenames differ from upstream names.
The project's existing CSS differs in comments/formatting and local references;
its exact bytes, weights 400/700 and Unicode ranges are preserved. No font data
was renamed, regenerated or replaced for this licensing correction.

The pinned merged-font source selects a ZhenKai source file whose SHA-256 equals
the official v0.819 release asset. `LXGWZhenKai-OFL.txt` is the license from
that version's commit `f98cd0b197e80211e7f77e9171d29d0659b430bf`; its copyright
header declares no Reserved Font Names. A newer ZhenKai license with RFNs was
previously collected without identifying this historical source. The correction
uses version-specific evidence, not the newer web-only naming exception.

Complete source URLs, archive/source hashes, local file hashes and upstream shard
member mappings accompany the font as `provenance.json`. The other preserved
license texts are `JetBrainsMono-OFL.txt`, `LXGWWenKaiScreen-OFL.txt`,
`NerdFonts-JetBrainsMono-OFL.txt` and `NerdFonts-LICENSE.txt`.

The production page links a same-origin `font-licenses.txt` asset containing this
notice, the full license texts and source provenance. Its bytes are included in
the verified immutable bundle namespace. The same evidence accompanies native
archives and container packages. This records a technical, version-specific
licensing assessment and does not provide a legal guarantee.
