# JetBrainsLxgwNerdMono web font

Exta's interface font is `JetBrainsLxgwNerdMono` Version 1.3 by lvbibir
(<https://github.com/lvbibir/JetBrainsLxgwNerdMono>), a merge of JetBrains Mono
NL Nerd Font Mono (Nerd Fonts v3.4.0) with LXGW WenKai Mono GB Screen v1.521
(Regular CJK) and LXGW ZhenKai GB (Bold CJK). The font name table declares:
"This font is licensed under the SIL Open Font License, Version 1.1. JetBrains
Mono: OFL-1.1, LXGW WenKai: OFL-1.1, Nerd Fonts: MIT."

The WOFF2 shards and `result.css` files in `JetBrainsLxgwNerdMono-Regular/`
(344 faces, weight 400) and `JetBrainsLxgwNerdMono-Bold/` (324 faces, weight 700)
were generated by `cn-font-split@7.6.6` and are byte-identical copies of the
assets in the LitRadar project (`app/assets/`, commits 70096be0 and 80075fab).
Each face declares a `unicode-range`, so browsers download only the shards
containing characters that a page actually renders.

The upstream merged-font repository contains no separate license file. The
license texts here were retrieved on 2026-10-25 from the component projects:

- `JetBrainsMono-OFL.txt`: JetBrains/JetBrainsMono, tag v2.304, `OFL.txt`
- `NerdFonts-LICENSE.txt`: ryanoasis/nerd-fonts, tag v3.4.0, `LICENSE`
- `LXGWWenKaiScreen-OFL.txt`: lxgw/LxgwWenKai-Screen, tag v1.521, `OFL.txt`
- `LXGWZhenKai-OFL.txt`: lxgw/LxgwZhenKai, default branch commit 524b675c, `OFL.txt`
  (the exact ZhenKai release used upstream is not recorded)

The fonts are delivered only as same-origin web font shards and are not
distributed as installable desktop fonts.
